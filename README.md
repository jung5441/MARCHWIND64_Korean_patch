# 슈퍼로봇대전64 한글패치

Marchwind64 **Windows 전용** 한글패치 설치툴입니다.

**한글패치툴만 제공합니다. 원본 리컴파일러와 게임 ROM은 제공하지 않습니다.** 패치툴에는 한국어 번역 및 한글 실행에 필요한 수정 구성요소가 들어 있습니다.
리컴파일 원본이 업데이트 될 때 같이 업데이트 관련 작업하여 매번 판올림 진행합니다.

## 설치 준비

- 공식 Marchwind64 **Windows x64** ZIP 또는 압축 해제한 공식 게임 폴더
- 사용자가 직접 보유한 **슈퍼로봇대전64 일본판 Rev 0 원본 ROM** (`.z64`, `.v64`, `.n64`)
- 한글판을 설치할 **새 폴더**

원본 리컴파일러의 다운로드, 설치, 사용법과 조작 방법은 **공식 제작자 사이트**에서 확인하세요.

**공식 사이트:** https://github.com/dyzz/srw64-recomp

## 설치 방법

1. `SRW64_KO_Installer_R4.exe`를 실행합니다. 별도의 Python 설치는 필요하지 않습니다.
2. 공식 Marchwind64 v0.4.8 ZIP 또는 게임 폴더를 선택합니다.
3. 본인이 가지고 있는 원본 ROM을 선택합니다.
4. 새 설치 폴더를 지정하고 **호환성 검사** 후 **한글패치 설치**를 누릅니다.
5. 설치된 폴더에서 `Start_SRW64_KO.cmd`로 게임을 실행합니다.

## 중요 — 원본 ROM 보존

**원본 ROM은 절대 삭제하지 마세요. 파일 이름도 바꾸지 말고, 저장 위치(경로)도 옮기지 마세요.**

설치툴은 선택한 원본 ROM 경로를 기억하고 게임 실행 시 다시 확인합니다. 설치 이후 ROM을 삭제하거나 이름·위치를 변경하면 한글판이 실행되지 않을 수 있습니다.

설치툴은 **기존 원본 리컴파일러 파일, 원본 ROM, 사용자 세이브를 삭제하거나 덮어쓰지 않습니다.** 원본과 설치한 한글판을 모두 보관해 주세요.

## 참고 사항

- 이 설치툴은 공식 리컴파일러 **v0.4.8**만 지원합니다. 공식 리컴파일러가 업데이트된 경우 호환되는 한글패치툴 버전을 확인하세요.
- 원본 리컴파일러의 사용 방법은 위 공식 사이트를 참고하세요.
